# 🌡️ EasyTemp – Arduino Temperature Monitor

**EasyTemp** is a simple and effective temperature monitoring system built using Arduino. It reads real-time temperature data from a sensor and can display the information on a connected website or local interface.

## 🔧 Features

-  Real-time temperature readings
-  Powered by Arduino Uno/Nano
-  Optional web interface for remote monitoring


## 🛠️ Hardware Requirements

- Arduino Uno or Nano
- DHT11 or DHT22 temperature sensor
- USB cable
- Breadboard and jumper wires
- (Optional) ESP8266 or similar module for Wi-Fi connectivity

##  Software Requirements

- Arduino IDE
- DHT sensor library
- (Optional) Web server or ESP8266 firmware for online display


## 🌐 Optional Web Display

For online viewing, pair EasyTemp with:
- ESP8266 to send data to a local server
- A basic HTML/JavaScript webpage to display readings
